# HİS OTOMASYON — Fotoğraf ekleme rehberi

Site GitHub Pages üzerinde yayınlanır. Fotoğrafları yüklemek için kod yazman gerekmez.

## Fotoğraf yükleme

1. Bu depoda `images` klasörünü aç.
2. **Add file → Upload files** seç.
3. Bilgisayarından fotoğrafları seçip yükle.
4. Dosya adlarını aşağıdaki gibi yaz; boşluk ve Türkçe karakter kullanma.
5. **Commit changes** ile kaydet. Site birkaç dakika içinde güncellenir.

## Ana sayfa ve hizmet fotoğrafları

- `hero-pano.jpg` — ana sayfadaki büyük pano fotoğrafı
- `kumes-otomasyonu.jpg` — kümes otomasyonu
- `elektrik-panolari.jpg` — elektrik panoları
- `plc-kontrol.jpg` — PLC ve kontrol sistemleri
- `motor-yemleme.jpg` — motor/yemleme ekipmanları

Galerideki altı fotoğrafın dosya adları:

Her yeni fotoğrafı bu adlardan biriyle yükleyerek ilgili görseli değiştirebilirsin. Aynı dosya adı varsa GitHub yeni yüklemede mevcut dosyanın değiştirilmesini ister; emin değilsen önce eski dosyayı açıp kontrol et.

## İpuçları

- JPG veya PNG kullanabilirsin; HTML'deki dosya adı uzantıyla birebir aynı olmalı.
- Fotoğraf dosyalarını mümkünse 500 KB–1,5 MB aralığında tut; site daha hızlı açılır.
- Yalnızca kendi çektiğin veya kullanma iznin olan fotoğrafları yayınla.
- Logo, depo kökündeki `logo.svg` dosyasıdır. İleride PNG istersen ayrıca `logo.png` yükleyebiliriz.
